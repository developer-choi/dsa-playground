# Graph

## 용어

### 그래프 (Graph)

노드와 그 노드들을 잇는 간선으로 이루어진 자료구조. "무엇과 무엇이 연결되어 있는가"를 표현한다.

### 노드 (Node)

연결 관계를 가진 각각의 데이터. **정점(Vertex)** 이라고도 한다.

### 간선 (Edge)

노드 간의 관계를 나타낸 선.

### 인접 노드 (Adjacent Node)

간선으로 **직접** 연결된 노드. 한 다리 건너 닿는 노드는 인접 노드가 아니다.

## 종류

### 무방향 그래프 (Undirected Graph)

간선에 방향이 없다. 간선 하나가 양쪽 관계를 동시에 나타내므로, A가 B의 인접 노드면 B도 A의 인접 노드다.

예: 친구 관계 — 내가 상대의 친구면 상대도 내 친구다.

### 유방향 그래프 (Directed Graph)

간선에 방향이 있다. 간선 하나는 단방향 관계만 나타내고, 그 방향으로만 이동할 수 있다.
A → B 간선이 있어도 B → A로는 갈 수 없다 (그 방향 간선이 따로 있어야 한다).

예: 팔로우 관계 — 내가 상대를 팔로우해도 상대는 나를 팔로우하지 않을 수 있다.

```
무방향            유방향
로제 - 제니       로제 → 제니

로제, 제니 서로   로제에서 제니로만
오갈 수 있음      갈 수 있음
```

## 예시 (무방향)

```
로제 - 사나
 |
제니 - 딩코
```

- 노드: 로제, 사나, 제니, 딩코
- 간선: 로제-사나, 로제-제니, 제니-딩코
- 인접 노드
  - 딩코 → 제니
  - 제니 → 로제, 딩코
  - 로제 → 사나, 제니
  - 사나 → 로제

딩코와 로제는 간선으로 직접 이어져 있지 않으므로 인접 노드가 아니다.
제니를 거쳐야 닿는 관계다.

## 표현 방법

그래프를 코드로 옮기는 방법은 두 가지다: **인접 행렬**과 **인접 리스트**.

아래 예시는 위 그래프에 번호를 붙여 쓴다 — 제니 0, 딩코 1, 로제 2, 사나 3.
간선은 0-1(제니-딩코), 0-2(제니-로제), 2-3(로제-사나).

복잡도 표기의 **V는 노드(Vertex)의 개수**, **E는 간선(Edge)의 개수**다.
이 예시는 V = 4, E = 3.

### 인접 행렬 (Adjacency Matrix)

2차원 배열로 표현한다. `graph[a][b]` 는 "a와 b가 연결되었는가".

```
   0  1  2  3
0  X  O  O  X
1  O  X  X  X
2  O  X  X  O
3  X  X  O  X
```

```js
const graph = [
  [false, true,  true,  false],
  [true,  false, false, false],
  [true,  false, false, true ],
  [false, false, true,  false],
];

graph[0][2]; // true — 연결 확인 O(1)
```

무방향이면 대각선을 기준으로 대칭이다 (`graph[a][b] === graph[b][a]`).
그래서 간선을 넣을 때 `graph[a][b]` 와 `graph[b][a]` 를 둘 다 채워야 한다.

- 연결 확인: **O(1)**
- 공간: **O(V²)** — 연결 안 된 조합까지 전부 칸을 차지한다

### 인접 리스트 (Adjacency List)

각 노드마다 "그 노드에 연결된 노드들"만 나열한다.

```
0 -> 1 -> 2
1 -> 0
2 -> 0 -> 3
3 -> 2
```

```js
// 노드가 0..N-1 번호면 배열
const graph = [
  [1, 2],
  [0],
  [0, 3],
  [2],
];

// 노드 이름이 번호가 아니면 객체(Map)
const graph = {
  제니: ['딩코', '로제'],
  딩코: ['제니'],
  로제: ['제니', '사나'],
  사나: ['로제'],
};

graph[0].includes(2); // true — 0의 이웃을 훑어야 한다
```

- 연결 확인: **O(해당 노드의 이웃 수)** — 최악 O(V)
- 공간: **O(V + E)** — 실제 있는 간선만 저장한다

### 둘의 차이 = 시간 vs 공간

| | 연결 확인 | 공간 |
|---|---|---|
| 인접 행렬 | O(1) | O(V²) |
| 인접 리스트 | O(이웃 수), 최악 O(V) | O(V + E) |

행렬은 "0과 2가 연결됐나?"를 즉시 답하는 대신, 연결 안 된 조합까지 전부 저장한다.
리스트는 저장을 아끼는 대신, 연결 여부를 알려면 그 노드의 이웃을 훑어야 한다.

한편 **"한 노드의 이웃을 전부 순회"** 는 리스트가 O(이웃 수), 행렬이 O(V)로 리스트가 유리하다.
DFS/BFS는 이 순회를 반복하는 작업이라 보통 인접 리스트를 쓴다.
