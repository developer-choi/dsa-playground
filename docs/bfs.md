# BFS (너비 우선 탐색)

갈라진 갈래를 한 단계씩 고르게 넓혀 나간다.
DFS와의 비교는 [dfs-bfs.md](./dfs-bfs.md), 그래프 자체는 [graph.md](./graph.md).

## 특징

- 큐로 짠다 (DFS는 스택).
- 같은 단계의 노드를 전부 큐에 담아두므로 공간은 **O(최대 너비)**.
- **가까운 것부터** 보므로, 목표에 처음 닿은 순간이 곧 최단 경로다. 거기서 멈추면 된다.
  (단, 간선 가중치가 모두 같을 때. 가중치가 제각각이면 다익스트라 등이 필요하다.)

## 아직 안 배운 것

여기부터는 실제로 문제를 풀면서 채운다. 지금 적어두면 검증 안 된 필기가 된다.

- 큐 구현 (`arr.shift()`는 O(N)이라 함정 — `let head = 0; queue[head++]` 인덱스 방식)
- 단계(레벨)를 세는 방법
- 최단 거리 문제에서의 적용
