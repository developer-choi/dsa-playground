# 완전탐색 vs DP vs 그리디

셋 다 "어느 선택지를 고를까"를 다루는 도구다. 차이는 **갈래를 몇 개나 보느냐** 하나다.

## 완전탐색

가능한 경우를 하나도 빼놓지 않고 다 만들어 본다. 답을 놓치지 않는 대신 갈래 수만큼 시간이 든다.

## DP

완전탐색과 같은 갈래를 그린다. 다만 **같은 입력이 다시 나오면 계산하지 않고 적어둔 값을 쓴다.** 겹치는 게 있을 때만 이득이고, 없으면 표를 지고 다니는 만큼 손해다. ([dp.md](./dp.md))

## 그리디

갈래를 아예 안 벌린다. 매번 제일 좋아 보이는 하나만 고르고 뒤를 안 돌아본다. 빠르지만 **그 선택이 항상 최선이라는 게 보장될 때만** 맞다. 안 되면 그냥 오답이다.

가짓수를 세는 문제에는 못 쓴다. 한 줄기만 타므로 나머지 경로를 셀 방법이 없다.

## 한 줄로

완전탐색은 다 본다. DP는 겹치는 걸 한 번만 본다. 그리디는 한 줄기만 본다.

## 떠올리는 순서

1. 구하는 게 "가짓수"인가 → 그리디는 아예 불가. 완전탐색으로 모든 경로 집계.
2. 구하는 게 "최소/최대"인가 → 그리디 가능성 탐색.
3. "매번 가장 좋아 보이는 걸 고르면 전체도 최선이다"가 머릿속에서 성립하는가 → **그리디**.
4. 성립 안 된다 → **완전탐색** 또는 DP.
