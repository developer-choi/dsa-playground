# 소수 구하기

출처: 백준 1929

## 문제 설명

정수 n을 입력받아, n 이하의 소수를 모두 오름차순으로 담은 배열을 반환하시오.

소수란 1과 자기 자신만을 약수로 가지는 1보다 큰 자연수를 말한다.

## 제한사항

- n은 1 이상 1,000,000 이하의 정수입니다.

## 입출력 예

| n | result |
|---|--------|
| 20 | [2, 3, 5, 7, 11, 13, 17, 19] |

### 예제 설명

20 이하의 소수는 2, 3, 5, 7, 11, 13, 17, 19 입니다.
